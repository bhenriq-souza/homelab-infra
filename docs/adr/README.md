# ADR

Architecture Decision Records registram decisões relevantes do laboratório.

## Quando criar uma ADR
- escolha de ferramentas principais
- mudança de topologia de rede
- mudança estrutural de repositórios
- mudança de estratégia de deploy ou IaC

## Estrutura recomendada
- status
- contexto
- decisão
- consequências
- alternativas consideradas
